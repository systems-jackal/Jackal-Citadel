# 📚 Go Networking Library

Reference books for the Go networking projects in this citadel.

| # | Book | Focus | File |
|:-:|------|-------|------|
| 1 | *Network Programming with Go* (Adam Woodbeck, No Starch, 2021) | TCP/UDP, sockets, secure and reliable network services | [PDF](books/Network-Programming-with-Go.pdf) |
| 2 | *Practical Go* (Amit Saha, Wiley, 2021) | Building scalable network and non-network applications | [PDF](books/Practical-Go.pdf) |
| 3 | *Building RESTful Web Services with Go* | HTTP and REST APIs in Go | [PDF](books/Building-RESTful-Web-Services-with-Go.pdf) |
| 4 | *Distributed Services with Go* (Travis Jeffery, Pragmatic, 2021) | Reliable, scalable, maintainable distributed systems | [PDF](books/Distributed-Services-with-Go.pdf) |

## Suggested reading order

1. **Network Programming with Go** for the networking fundamentals.
2. **Practical Go** for building real applications.
3. **Building RESTful Web Services with Go** for HTTP APIs.
4. **Distributed Services with Go** once the basics feel solid.
