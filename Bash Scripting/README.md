# BASH 
Bash is a shell or a command line interpreter for the GNU operating system.
The name is an achronym from `BORNE-AGAIN SHELL`

`SHELL` is a macro processor that executes commands.
The term macro processor is a functionality where text and symbols are expanded to create larger expressions.

## Definations 
- `POSIX` : A family of open standards based in UNIX.Bash primarily concerned with the shell and utility portions of the `POSIX 1003.1` standard.
- `blank` : a space or a tab character.
- `whitespace` : a character belonging to the space character class in the current locale or for which `isspace()` return true.
- `builtin` : command that is implemented internally by the shell itself rather than by an excutable program somewhere in the file system.
- `control operator` : a token that perfoms a control function.It is a new line or a one of the following : `‘||’, ‘&&’, ‘&’, ‘;’, ‘;;’, ‘;&’, ‘;;&’, ‘|’, ‘|&’, ‘(’, or ‘)’. `.
- `exit status` : a value returned by a command to its caller.Value is restricted to 8 bit so the maximum value is `255`.
- `field` : a unit of shell that is a result of one of the shell expansion.
- `filename` : A string of characters used to identify a file.
