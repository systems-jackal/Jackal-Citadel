## Tux Arena ##
**Leveraging Learning Fundamentals by going through linux war games and CTF.**
Wargames are puzzle-based, hands-on challenges accessed over SSH or a browser, where each level teaches a specific skill by making you actually use it to get to the next level. They sit alongside the Linux Upskill Challenge, not instead of it — the course teaches concepts in order; wargames force you to apply them under pressure, without being told exactly which command to run.
